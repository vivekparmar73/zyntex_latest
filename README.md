# Zyntex website

React 19 + Vite. Smooth scrolling (Lenis), animation (Framer Motion), self-hosted fonts (Montserrat + Inter).

## Commands

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # serve the production build
npm run images   # regenerate optimised images from /resources
```

## Where things live

| Path | What |
| --- | --- |
| `resources/` | **Original** supplied assets (untouched masters); `resources/brand/` holds the logos extracted from the brand PDF |
| `src/assets/images/` | Web-optimised WebP copies generated by `npm run images` (plus product tiles cut from `MAIN IMAGE - 1`) |
| `src/data/site.js` | Contact details, coordinates, statistics, workforce figures, leadership list, product labels |
| `src/i18n/translations.js` | Interface text; the selector lists 17 language/country options (Arabic options are right-to-left) |
| `src/pages/` | One file per page |
| `src/components/` | Header, footer, language selector, intro animation, design carousel, 3D product ring, motion helpers |
| `src/styles/` | Design tokens (`global.css`) and component/page styles |

To add a new image: drop it in `resources/`, add it to `scripts/optimize-images.mjs`, run `npm run images`, and export it from `src/assets/images/index.js`.

## Routes

`/` home (logo intro once per session) · `/our-journey/` · `/apparel-designer/` · `/clothing-and-apparel-manufacturers/` · `/products/` · `/operational-excellence/` · `/about-us/` · `/leadership/` · `/contact-us/` · `/sitemap/` · `/privacy-policy/`

Old URLs `/apparel/` and `/integrated-systems/` redirect to `/`.

## Contact form

The form posts to `VITE_CONTACT_ENDPOINT` (see `.env.example`). It defaults to FormSubmit, which delivers to info@zyntex.in. The **first** submission triggers a one-time activation email to that inbox, and it must be confirmed before messages are delivered.

## Hosting

This is a single-page app, so every route must serve `index.html`. The fallbacks are already included: `public/.htaccess` (Apache/cPanel/Hostinger), `public/_redirects` (Netlify) and `vercel.json` (Vercel).
